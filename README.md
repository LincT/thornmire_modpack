# Thaumesque modpack

> Used to manage mods and syncing between client and server for quality of life. Generally this works better than skeevy random zips from the internet even though that is still a common practice

# Versioning:
```
x.x.x  
    ^ = config file updates, recipes, cosmetic changes such as resource packs added 
  ^   = new mods added / removed entirely, or updated minecraft mod binary version to apply latest patches from mod publisher
^     = minecraft version/forge version/mod loader changed
```
> This is done to respect Semver guidelines even though a modpack isn't 100% the same as software releases.
> The main distinction is first or second number changes will most likely require update, third digit changes most likely would affect the experience but not prevent one from connecting to a server
